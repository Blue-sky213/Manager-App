# Noir Manager บน Android

มี 2 ทาง เลือกทางเดียวพอ

| ทาง | ต้องลงอะไรในคอม | เหมาะกับ |
|---|---|---|

## A. โหลด APK จาก GitHub (ไม่ต้องตั้ง SDK)

CI สร้างไฟล์ติดตั้งให้ทุกครั้งที่มี PR หรือ merge เข้า main

1. เปิด GitHub → repo `Manager-App` → แท็บ **Actions**
2. คลิกงานล่าสุดที่มีเครื่องหมาย ✅ (ชื่อ *Flutter CI*)
3. เลื่อนลงล่างสุด หัวข้อ **Artifacts** → กด **noir-manager-android** → ได้ไฟล์ `.zip`
4. แตก zip → ได้ `app-arm64-v8a-release.apk`
5. ส่งไฟล์เข้ามือถือ (LINE ส่งให้ตัวเอง / Google Drive / สาย USB)
6. บนมือถือ แตะไฟล์ `.apk` → ถ้าขึ้น *ไม่อนุญาตแอปจากแหล่งที่ไม่รู้จัก* → **การตั้งค่า** → เปิด **อนุญาตจากแหล่งนี้** → กลับมากด **ติดตั้ง**
7. Google Play Protect อาจเตือน *แอปไม่รู้จัก* → **ติดตั้งต่อไป** (เพราะไม่ได้มาจาก Play Store)

> ไฟล์ใน Artifacts เก็บ 14 วัน · อัปเดตแอป = ลง APK ใหม่ทับ ข้อมูลเดิมยังอยู่

## B. รันจาก VS Code ผ่านสาย USB

### ตั้งในคอมครั้งเดียว
1. ลง **Android Studio** จาก developer.android.com/studio → เปิดครั้งแรก กด *Next* ตามค่าเริ่มต้น (มันจะโหลด SDK ให้)
2. Android Studio → **More Actions → SDK Manager** → แท็บ **SDK Tools** → ติ๊ก **Android SDK Command-line Tools** → *Apply*
3. เปิด PowerShell แล้วรัน
   ```powershell
   flutter doctor --android-licenses   # กด y ทุกข้อ
   flutter doctor                      # บรรทัด Android toolchain ต้องเป็น ✓
   ```

### ตั้งในมือถือครั้งเดียว
1. **การตั้งค่า → เกี่ยวกับโทรศัพท์** → แตะ **หมายเลขบิลด์** 7 ครั้ง → เปิดโหมดนักพัฒนา
2. **ตัวเลือกสำหรับนักพัฒนา** → เปิด **การแก้ไขข้อบกพร่อง USB**
3. เสียบสายเข้าคอม → มือถือถาม *อนุญาตการแก้ไขข้อบกพร่อง USB?* → **อนุญาต**

### รัน
```powershell
cd C:\dev\projects\Manager-App\noir_manager
flutter devices          # ต้องเห็นชื่อมือถือ
flutter run -d <ชื่อหรือไอดีมือถือ>
```

- จอแคบ → เมนูอยู่ด้านล่าง · ตั้งค่า = ไอคอน ⚙ มุมขวาบน
