## 4. สิ่งที่นัวร์ช่วยกันพลาดได้

| เรื่อง | ทำแบบนี้ |
|---|---|
| ย้ายเครื่อง / ล้างเครื่อง | เปิดแอปเครื่องเก่า → ซิงก์ให้เสร็จ (ชิปสถานะ "บันทึกแล้ว") ก่อนเลิกใช้ |
| SQL / ตั้งค่าเว็บที่ได้รับ | รันแล้วส่ง screenshot "Success" กลับมา · ตั้งชื่อ query ตามเลขไฟล์ (`002 sticker files`) |
| merge PR | merge ตามลำดับที่เขียนใน PR · PR ที่ขึ้น schema → สำรองข้อมูลก่อนเปิดแอป |
| กติกาเงิน / งาน | คุยกับคนที่เกี่ยว (พ่อ) ให้จบก่อนสั่งทำ แล้วเล่าเป็นตัวอย่างวันจริง 2–3 วัน |
