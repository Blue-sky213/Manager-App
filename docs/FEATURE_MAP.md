# Feature Map — Noir Manager

แผนที่ฟีเจอร์ที่ **มีอยู่จริงในโค้ดตอนนี้** · คอลัมน์ "หลักฐาน" คือสิ่งที่ verify ใช้เช็ก
อัปเดตไฟล์นี้ในงานเดียวกับที่แก้ฟีเจอร์เสมอ · อัปเดตล่าสุด: 9 พ.ย. 2026 (DB v12)

สถานะ: ✅ มีเทสอัตโนมัติ · 🖐️ ต้องเช็กด้วยมือ · ⚠️ ยังไม่ได้เช็ก

## วิชา

| ฟีเจอร์ | เข้าถึงยังไง | หลักฐาน | สถานะ |
|---|---|---|---|
| **Android**: CI สร้าง APK (arm64) ทุก PR / main → โหลดจาก Actions → Artifacts ลงมือถือได้เลย ไม่ต้องตั้ง SDK · ชื่อแอป "Noir Manager" · ไอดี `com.noirmanager.app` · วิธีลงทีละขั้น `docs/ANDROID.md` | GitHub Actions | งาน `android-apk` ใน CI | ✅ / 🖐️ |
| **สติกเกอร์อารมณ์ (v16)**: การ์ด "วันนี้รู้สึกยังไง?" ในหน้าวันนี้ → แปะได้หลายชิ้นต่อวัน · คลิก = เขียนโน้ต · คลิกขวา = โน้ต / ลอกออก · ตารางเดือนโชว์สติกเกอร์แรกของวัน · **ชุดในแอป** อารมณ์ (8) + การทำงาน (6) ซ่อนได้ ลบไม่ได้ · **เพิ่มเอง** เป็นชุดใหม่ หรือทีละชิ้น (ลง "สติกเกอร์ของฉัน") ด้วยอีโมจิ (1 ตัว) **หรือรูปของตัวเอง** (ย่อด้านยาวเหลือ 256px เก็บในโฟลเดอร์ `stickers` ของแอป · สำรองไปด้วย) · **ชุดจากรูป**: เลือกหลายรูป → เป็นชุดเลย (ชื่อ = ชื่อไฟล์) · **หัววันในตารางสัปดาห์** มีสติกเกอร์เล็กมุมขวาบนเลขวัน (ชี้ = เห็นทุกชิ้น) | วันนี้ · ปฏิทินเดือน · ตั้งค่า → สติกเกอร์อารมณ์ | `sticker_test` | ✅ / 🖐️ |
| **สำรอง / กู้ข้อมูลในแอป**: สำรองอัตโนมัติวันละครั้งตอนเปิดแอป · ปุ่ม "สำรองตอนนี้" · เก็บ 30 วัน (วันเดียวกันทับ) · กู้คืน → สำรองของตอนนี้ไว้ก่อน (before-restore) แล้วทับตอนเปิดแอปครั้งถัดไป · ไฟล์อยู่ที่โฟลเดอร์ `backups` ข้างไฟล์ DB | ตั้งค่า → สำรองข้อมูล | `backup_test` | ✅ / 🖐️ |
| **คำถามแรกเข้า**: เปิดแอปครั้งแรก ถาม 5 ข้อ → โหมดแอป · **บรรยากาศที่ชอบ** (ห้องสว่าง / ห้องมืด / ตามเวลา + สีที่ทำให้อยากเริ่มทำ → ลองธีมสดทันที) · เวลาตื่น/นอน (ผู้ใช้เดิมเริ่มจากค่าเดิม ไม่ทับถ้าไม่แตะ) · "อยากเปลี่ยนอะไรในตัวเอง" (เก็บคำของผู้ใช้ไว้ใช้ในข้อความสะท้อนผลรายปี) · เป้า GPA · ข้ามทั้งหมดได้ · ไม่ถามซ้ำ | เปิดแอปครั้งแรก | `onboarding_test` | ✅ / 🖐️ |
| **🔒 ล็อกงานที่เริ่มแล้ว + คำมั่น**: ถึงเวลาเริ่มแล้ว → กรอกผล (ทำแล้ว · บันทึกเรียน) ได้ปกติ · เลื่อน / ยกเลิก / แก้เวลา / แก้ไข / ลบ ต้องยืนยัน · คลิกขวา → **คำมั่น (ล็อก)…** ตั้งความตั้งใจ เช่น "ผมต้องการทำต่อเนื่องโดยไม่เว้น" → ตอนจะแก้ แอปยกคำนั้นมาถาม: ไม่แก้ ทำต่อ / แก้ครั้งนี้ / เลิกตั้งใจข้อนี้ · ปิดทั้งแอปได้ในตั้งค่า · **กุญแจ 🔒 หน้าชื่องาน** = มีคำมั่น หรือเริ่มแล้วแต่ยังไม่กรอกผล | ปฏิทิน · วันนี้ · ตั้งค่า | `widget_test` (🔒) | ✅ / 🖐️ |
| **ตัวติดตั้ง Windows**: CI สร้าง `NoirManager-Setup-<เวอร์ชัน>.exe` (Inno Setup) ทุก PR / main → ดับเบิลคลิกติดตั้ง ไม่ต้อง admin · ไอคอน Start menu (+ เดสก์ท็อปถ้าติ๊ก) · ถอนได้จาก Settings ของ Windows · ข้อมูลแอปอยู่คนละที่ ถอนแล้วไม่หาย · ติดตั้งทับ = อัปเดต | GitHub → Actions → artifact `noir-manager-windows-setup` | CI job `windows-installer` | ✅ / 🖐️ |
| **ทดลองหน้าจออุปกรณ์ (บนคอม)**: วาดแอปในกรอบขนาดจอจริง iPhone 15 · iPhone SE · iPad 10.9" · iPad mini · Android มือถือ · Android จอเล็ก · Android แท็บเล็ต · แนวตั้ง / แนวนอน · iPhone/iPad ใช้ลักษณะ iOS (การเลื่อน / เปลี่ยนหน้า) · จำค่าไว้ · **มือถือแนวตั้ง** (กว้าง < 560): หัววิชาวงกลม % ขึ้นแถวบนคู่รหัส ชื่อวิชาเต็มความกว้าง · แท็บวิชา 5 อันกว้างเท่ากันแถวเดียว · การ์ดภาพรวมเต็มความกว้าง · ไม่ใช่ระบบจริง (ไม่มีแป้นพิมพ์มือถือ / สัมผัสหลายนิ้ว) | ตั้งค่า → ทดลองหน้าจออุปกรณ์ (เฉพาะ Windows) | `device_preview_test` (7 เครื่อง × 2 แนว ทุกหน้า · มือถือแนวตั้ง: แท็บแถวเดียว · การ์ดกว้างเท่ากัน) | ✅ / 🖐️ |
| **ทำแล้ว = บันทึกเรียน (12 พ.ย.)**: กด "ทำแล้ว" ที่คาบเรียน → แผ่นเดียว (มือถือ = แผ่นล่าง · คอม = กล่องกลาง): บทที่เรียน (เดาให้) · หัวข้อ · จบบทไหม · ☆ การบ้าน · **เวลาเลิกจริง** · ปุ่ม "แค่ทำแล้ว ไม่บันทึก" / "บันทึก" · เมนู "บันทึกเรียนถึงไหน" ที่ซ้ำถูกเอาออก (ทำแล้วจะมี "แก้บันทึกเรียน · เวลาเลิก") · ปิดถามได้ในตั้งค่า → เรียน · ติว | ปฏิทิน · วันนี้ · ตั้งค่า | `study_flow_test` | ✅ / 🖐️ |
| **ติวตามบทที่เรียนถึง**: ขอบเขตติว = บท 1 → บทที่บันทึกว่าเรียนถึง · "ติวก่อน" = 3 หัวข้อคะแนนอ่อนสุด (ยังไม่ประเมิน = อ่อนสุด) · **Advanced**: สัปดาห์ที่มีคาบ → ติวอย่างน้อย 1 รอบ (`max(1, เป้า − คาบ)`) · บทที่เรียนแล้วเฉลี่ยถึงเกณฑ์ (70/80/90% ค่าเริ่ม 80) → "ผ่าน · พักได้" เลือก พักสัปดาห์นี้ / ติวต่อ · ปุ่ม "ติวเพิ่ม" เมื่อครบแล้ว · "อ่านบทถัดไปล่วงหน้า" (ไม่บังคับ) | วิชา → แท็บติว · ตั้งค่า → เรียน · ติว | `study_flow_test` | ✅ / 🖐️ |
| **เรียน vs ติว แยกชัด**: คาบเรียน = พื้นสีวิชาเต็ม · รอบติว = พื้นจาง + **กรอบเส้นประ** สีวิชา + ไอคอน ✎ · ทับเวลา = กรอบแดง (ทุกมุมมอง) | ปฏิทิน · วันนี้ | CI | ✅ / 🖐️ |
| **ปฏิทินสัปดาห์บนมือถือ** (กว้าง < 720): แถบ 7 วัน จ → อา ด้านบน (แถบเล็กใต้เลข = ทำไปกี่ส่วน) · ไทม์ไลน์วันที่เลือก เวลาซ้าย กิจกรรมต่อท้าย · ปัดซ้าย/ขวาเปลี่ยนวัน | ปฏิทิน → สัปดาห์ | `study_flow_test` | ✅ / 🖐️ |
| **ความสำเร็จ**: งานสุดท้ายของวันเสร็จ → แถบแจ้ง "ครบทุกงานวันนี้ · สตรีค n วัน" · วันครบ = จุดเขียว + แถบเขียวในแถบ 7 วัน · หน้าสถิติ: สตรีค (วันว่างไม่ตัด · วันนี้ยังไม่จบไม่ตัด) + เหรียญ ครบทั้งวัน · สตรีค 7/30 · จบบท · ทวนผ่านเกณฑ์ (คำนวณจากข้อมูลเดิม ไม่เพิ่มตาราง) | สถิติ · ปฏิทิน | `achievements_test` | ✅ / 🖐️ |
| **หน้าวิชา minimal (มือถือ)**: ชิปวิชาทั้งปี → ปุ่มเดียว "เปลี่ยนวิชา · ปี n · x วิชา ▾" เปิดแผ่นล่าง · ตารางเรียนทั้งสัปดาห์ / เกรดและหน่วยกิต ย้ายเข้า ⋯ · การ์ดภาพรวมไม่มีขอบ | การเรียน | `device_preview_test` | ✅ / 🖐️ |
| **หน้าจองเวลา (หาเวลาติว)**: ความยาวรอบอยู่บนสุด · **สัปดาห์** = 7 คอลัมน์ × เวลา เส้นทุกชั่วโมง (ประครึ่งชั่วโมง) · ทุกกล่องมีชื่อ + ไอคอน 🎓 เรียน · ✎ ติว (เส้นประ) · ⇄ แทนได้ (ลายขีด จองทับได้) · 🔒 ล็อก (ทับไม่ได้) · ★ แนะนำ 3 ช่อง · แตะช่องเขียว = เลือก (ปัด 15 นาที ขยับให้พอดีช่อง) · ‹ › เปลี่ยนสัปดาห์ · **เดือน** = ชั่วโมงว่างต่อวัน 3 ระดับ (เขียวอ่อน < 3 · กลาง 3–7 · เขียวเข้ม 7+) แตะวัน → สัปดาห์นั้น · มือถือเต็มจอ | วิชา → ติว → จองเวลาติว | `booking_notebook_test` | ✅ / 🖐️ |
| **การ์ดติวย่อ + ตั้งค่าสติกเกอร์ย่อ**: การ์ดติวเหลือ สถานะ · เรียนถึงบท · ติวก่อน · ปุ่มจองเต็มความกว้าง · สติกเกอร์ชุดละแถว (5 รูปแรก + จำนวน + สวิตช์) แตะ = แผ่นตารางรูป · ✕ / ลบทั้งชุด เฉพาะตอนกด "แก้ไข" | วิชา → ติว · ตั้งค่า | CI | ✅ / 🖐️ |

| **~~สมุด (มุมมองแยก)~~ → รวมเข้า "เดือน" แล้ว (12 พ.ย. รอบ 3)**: ปฏิทินเดือนแบบกระดาษ เทปชื่อเดือน · สติกเกอร์ชิ้นแรกใหญ่กลางช่อง (เอียงเล็กน้อย) ชิ้นที่ 2 เล็กมุม · มุมขวาบน ⭐ ส่งงาน 📝 สอบ · ล่างซ้าย 🎓n คาบ ✎n ติว · กรอบเขียว = ทำครบทั้งวัน · คำอธิบายใช้สัญลักษณ์เดียวกับในช่อง · สรุปเดือนเป็นป้ายแยกเรื่อง · ดูอย่างเดียว แตะวัน = สรุปวัน · ‹ › ย้อนหลัง / ล่วงหน้า | ปฏิทิน → มุมมอง "สมุด" | `booking_notebook_test` | ✅ / 🖐️ |
